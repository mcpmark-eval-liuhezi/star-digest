# star-digest

The open-source projects I depend on, via my stars.

This repository turns my GitHub starred-repositories list — otherwise just an unreadable
pile of bookmarks — into a presentable inventory that I can actually use as source
material for talks and reference.

## What's in here

- **STARS.md** — a table of the starred repositories (owner/name + link) that I actually
  depend on, captured from the live starred-repositories list.
- **CONTRIBUTING.md** — how to refresh the inventory when the list goes stale.

## How big is the list?

The live lookup of my starred repositories returned **6 repositories**.

That's the whole list as it stands right now — no padding, no guessing. Small enough to
know cold, and a good starting point for a brown-bag talk about the open-source
projects behind my day-to-day work.

*This digest is a point-in-time snapshot; the starred list will drift over time.*
